### Selisa_Chatbot

An ELIZA-style conversational chatbot featuring a web interface that launches in your web browser. Built primarily with Python, this project revives classic rule-based AI with a modern web experience. 

### Features

* **Classic ELIZA Engine:** Employs pattern matching and psychotherapist-style responses.
* **Web Interface:** Opens automatically in your default web browser for an interactive user experience.
* **Python-Driven Backend:** Lightweight, quick to set up, and easy to modify.

### Getting Started

### Prerequisites

Ensure you have Python installed if running locally, or a GitHub account if using a cloud environment. 

### Installation & Setup

You can run this project locally or entirely in the cloud: 

* **Option 1: Using GitHub Codespaces**
Click the "Code" button on this repository, select the "Codespaces" tab, and create a new codespace. The environment will set up automatically.
* **Option 2: Local Download**
Download the project files as a ZIP archive from GitHub and extract them into a folder on your computer.

Once inside the project directory, install the required web environment by running the following commands in your terminal: 

* pip install flask
* pip install flask-socketio

After installing the packages, you can start the application by running: 

* python main.py

### Running the Chatbot

The backend will start up and automatically launch your web browser to display the chat interface. 

### How It Works

Selisa_Chatbot acts as a Rogerian psychotherapist, reflecting your statements back to you as questions or prompts. The Python backend processes your inputs using predefined response patterns and serves them up instantly to the browser client.
